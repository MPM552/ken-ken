# Ken Ken

A web-based implementation of the Ken Ken puzzle game.

## Getting Started

### Start the Web Server

Make sure you have Python installed. Then run:

```bash
python -m http.server 8080
```

This will start a local web server on port 8080.

### Play the Game

1. Open your browser and navigate to `http://localhost:8080`
2. The game board will load automatically
3. Solve the puzzle by filling in the grid with numbers

## How to Play

Ken Ken is a logic puzzle similar to Sudoku:
- Fill each row and column with numbers (no repeats in a row/column)
- The numbers in each outlined region must combine (using the shown operator) to equal the target number
- Use logic and deduction to complete the puzzle

Enjoy!
